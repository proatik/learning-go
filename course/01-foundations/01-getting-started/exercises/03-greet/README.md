# Greet Someone

Implement:

```go
func Greet(name string) string
```

| Input | Output |
|---|---|
| `"Gopher"` | `"Hello, Gopher!"` |
| `"Rob"` | `"Hello, Rob!"` |
| `""` (empty) | `"Hello, World!"` |

## Rules
- Use string concatenation with `+` (no `fmt` needed).
- Handle the empty string with an `if`.
