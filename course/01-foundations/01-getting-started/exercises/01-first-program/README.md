# Your First Program

Write a complete Go **program** (not a library) in `main.go`.

When run, it must print exactly these two lines:

```
Hello from main!
2 + 3 = 5
```

## Rules
- The file must declare `package main` and a `func main()`.
- Compute the `5` in code from two variables `a := 2` and `b := 3` — don't hard-code the second line.
